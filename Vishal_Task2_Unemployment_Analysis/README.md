# Unemployment Analysis in India

## Overview

This project analyzes unemployment trends across different states in India using unemployment datasets.

## Objectives

- Analyze unemployment rates across states
- Identify regions with highest unemployment
- Compare urban and rural unemployment
- Study unemployment trends over time

## Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis Performed

1. Data Cleaning
2. Missing Value Handling
3. Exploratory Data Analysis
4. State-wise Unemployment Analysis
5. Time Series Trend Analysis
6. Urban vs Rural Comparison

## Key Findings

- Certain states show significantly higher unemployment rates.
- Unemployment increased sharply during 2020.
- Urban and rural unemployment patterns differ across regions.

## Conclusion

The project provides insights into unemployment patterns in India and demonstrates how data analytics can be used to identify economic trends.
